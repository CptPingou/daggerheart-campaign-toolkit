# P2.8k.3 — Conversion native Finisher (corrigé)

Règle conservée :
- Opener : 2 Hope
- Finisher : 1 Hope
- Support : 1 Hope

Conversion :
- vraie Action Foundryborne `MHFINACTION00001`, marquée `role: finisher`;
- `huntCardMechanic.hopeCost` corrigé de 0 à 1;
- `engagement-finisher.mjs` conserve `spendActorHope(..., 1)`;
- toute l'Opportunity disponible est engagée, plafonnée à 4 au Tier 1;
- réussite : `converted = X`;
- échec : `lost = X`;
- dans tous les cas Opportunity revient à 0.

Le coût n'est volontairement pas dupliqué dans l'ActionField Foundryborne :
`engagement-finisher.mjs` reste l'unique writer du coût en Hope.

NOTE : `monster-hunter-engagement-contract.mjs` n'était pas fourni avec les
sources de ce patch. Il doit recevoir `finisherHopeCost: 1` lors de la prochaine
passe afin que le contrat global expose explicitement cette règle.
