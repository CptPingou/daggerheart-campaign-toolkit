# P2.8k.4 — Conversion chat rule

Ajoute un message de chat après la résolution du Finisher.

Réussite :
- affiche le nombre réel d'OP engagées;
- rappelle `+X dés de dégâts de l'arme` OU un Effet;
- rappelle Effet standard = 2 OP, rare = 3 OP;
- rappelle critique = dégâts ET Effet.

Échec :
- indique X OP perdues;
- rappelle qu'aucun bonus de dégâts ni Effet n'est converti.

Aucun Damage Roll, Effet, ciblage ou autre résolution n'est automatisé.
Le compteur Opportunity reste remis à 0 par le resolver existant.
