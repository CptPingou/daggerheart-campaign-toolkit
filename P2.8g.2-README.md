# P2.8g.2 — Toolkit Card Families / Virtual Hunt Domain

Cette passe remplace la direction P2.8g.1, rejetée : **Chasse n'est pas un
troisième domaine Daggerheart**.

Les deux domaines natifs du personnage restent inchangés. Les cartes
transversales passent par une primitive générique Toolkit :

`Toolkit card -> family -> loadout policy -> mechanic`

Première famille :
- `hunt` / Chasse
- namespace `monster-hunter`
- max 2 cartes
- import indépendant du contrôle natif des domaines Foundryborne

Les 8 cartes Monster Hunter portent maintenant :

```js
flags["daggerheart-campaign-toolkit"].toolkitCard
```

avec `family: "hunt"`.

Le système est volontairement générique : les futures cartes `dragonmark`,
`house`, etc. pourront enregistrer leur propre famille et leur propre limite.

## Validation

Après extraction + F5, les 8 documents ont changé de flags :

```js
const api = game.modules.get("daggerheart-campaign-toolkit").api;
const before = await api.autonomousSourceStatus();
console.log(before.expected, before.actual, before.green);
console.log(before.packs["dh-domain-cards"]);

await api.syncAutonomousSources();

const after = await api.autonomousSourceStatus();
console.log(after.expected, after.actual, after.green);
console.log(after.packs["dh-domain-cards"]);
console.log(api.toolkitCardFamilies.status());
```

Attendu après sync :
- `811 811 true`
- `dh-domain-cards 239 / 239`
- famille `hunt`, `maxCards: 2`
- `status().green === true`

## Import réel sur un PJ

Sélectionner un PJ puis récupérer une carte depuis le compendium :

```js
const actor = canvas.tokens.controlled[0]?.actor;
const pack = game.packs.get("daggerheart-campaign-toolkit.dh-domain-cards");
const docs = await pack.getDocuments();
const opening = docs.find(d => d.name === "Ouverture");

console.log(api.toolkitCardFamilies.metadata(opening));
console.log(await api.toolkitCardFamilies.importCard(actor, opening));
console.log(api.toolkitCardFamilies.validateLoadout(actor, "hunt"));
```

L'import passe directement par le Toolkit et **ne modifie pas les deux domaines
de classe**.

Importer ensuite une deuxième carte Chasse : GREEN.

À la troisième :

```js
const conversion = docs.find(d => d.name === "Conversion");
const support = docs.find(d => d.name === "Appui défensif");

await api.toolkitCardFamilies.importCard(actor, conversion);
console.log(await api.toolkitCardFamilies.importCard(actor, support));
```

Attendu pour la troisième :
- `green:false`
- `imported:false`
- `reason:"max-loadout"`

Enfin :

```js
console.log(api.monsterHunterActorLoadout.inspect(actor));
console.log(api.monsterHunterActorLoadout.capabilities(actor));
```

P2.8g reste ainsi utilisable : il lit les cartes réellement embarquées sur le PJ.
