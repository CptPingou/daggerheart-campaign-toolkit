# P2.8h — Toolkit Card UI

Ajoute une première UI jouable aux familles de cartes Toolkit.

## Fonctionnement

Sur une fiche Actor `character`, un bouton cible apparaît dans l'en-tête.
Il ouvre le gestionnaire **Cartes Chasse**.

Le gestionnaire :
- liste les cartes Toolkit de famille `hunt` présentes dans `dh-domain-cards`;
- affiche le compteur `n / 2`;
- ajoute via `toolkitCardFamilies.importCard()`;
- retire via `toolkitCardFamilies.removeCard()`;
- désactive les ajouts lorsque la limite de famille est atteinte.

La contrainte native des deux domaines Daggerheart n'est pas modifiée.

La primitive d'UI utilise la famille Toolkit et non une exception mécanique
Monster Hunter. Les futures familles Eberron pourront réutiliser le même
gestionnaire.

## Validation

1. Extraire le patch et F5.
2. Ouvrir la fiche du PJ `test`.
3. Vérifier la présence du bouton cible dans l'en-tête.
4. Ouvrir **Cartes Chasse**.
5. Avec les deux cartes déjà présentes, le compteur doit afficher `2 / 2` et
   les autres boutons Ajouter doivent être désactivés.
6. Retirer une carte : compteur `1 / 2`.
7. Ajouter une autre carte : compteur `2 / 2`.
8. Vérifier dans la console :

```js
const api = game.modules.get("daggerheart-campaign-toolkit").api;
const actor = canvas.tokens.controlled[0]?.actor;
console.log(api.toolkitCardFamilies.validateLoadout(actor, "hunt"));
console.log(api.monsterHunterActorLoadout.capabilities(actor));
```

Attendu : GREEN et count 2.

Fallback de test si le bouton n'apparaît pas :

```js
await api.toolkitCardSheet.open(actor, "hunt");
```

Si ce fallback fonctionne mais pas le bouton, le problème est uniquement le
hook/DOM de la feuille Foundryborne et pourra être ajusté sans toucher au
runtime des familles.
