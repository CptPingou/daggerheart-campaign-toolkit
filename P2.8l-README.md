# P2.8l — Audit de reconstruction mécanique des cartes de domaine

Cette passe est **audit-only** : elle ne modifie aucune carte et ne copie encore
aucune mécanique native.

Elle compare les cartes Core autonomes du Toolkit à `daggerheart.domains`.

Correspondance prioritaire :
1. canonical/source id natif si disponible ;
2. slug anglais issu de notre `canonicalSourceId` ;
3. domaine ;
4. niveau.

API :

```js
const api = game.modules.get("daggerheart-campaign-toolkit").api;
const report = await api.auditNativeDomainCardMechanics();
report;
```

À me renvoyer :
- le tableau résumé ;
- si `unmatched > 0`, `report.unmatchedRows`;
- si `ambiguous > 0`, `report.ambiguousRows`.

`greenForReconstruction: true` signifie uniquement que les 210 cartes Core ont
une correspondance native unique suffisamment déterministe. La reconstruction
des `system.actions` / `effects` sera une passe séparée.
