# P2.8m.1 — Domain-card ActionField shape fix

Cause confirmée : l'export P2.8m avait sérialisé `system.actions` comme un tableau.
Foundryborne attend l'ActionField sous forme d'objet indexé par `_id`, et la validation
du DataModel supprimait donc les actions à `Item.createDocuments()`.

Correction :
- aucune mécanique n'est reconstruite à nouveau ;
- chaque tableau `system.actions` est converti en objet `{ [action._id]: action }` ;
- les 106 `effects` restent inchangés ;
- aucune dépendance runtime à `daggerheart.domains`.

Attendu après sync :
- Core : 190 cartes avec actions, 106 avec effects, 204 avec au moins une mécanique.
- Pack complet : mêmes nombres pour les actions/effects Core, plus toute mécanique
  propre aux cartes playtest/homebrew éventuellement présente.
