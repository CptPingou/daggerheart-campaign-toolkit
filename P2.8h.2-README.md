# P2.8h.2 — Chasse dans Loadout +

Remplace le bouton Chasse de la barre supérieure par une troisième action dans
le dialogue ouvert par `Loadout +`.

Le footer natif observé contient :
- `data-action="create"` → Create Item
- `data-action="browse"` → Browse Compendium

Le Toolkit ajoute :
- `data-dct-action="hunt"` → Chasse

Le bouton n'est injecté que lorsque les deux actions natives sont présentes,
afin d'éviter de modifier les autres DialogV2.

Au clic, le petit dialogue est fermé puis le gestionnaire de cartes Chasse
déjà validé est ouvert.

## Test
1. Extraire, F5.
2. Ouvrir un PJ.
3. Cliquer `Loadout +`.
4. Attendu : Create Item / Browse Compendium / Chasse.
5. Cliquer Chasse : ouverture du gestionnaire `hunt`.
6. Vérifier qu'il n'y a plus de bouton cible dans la barre de fenêtre.
