# P2.3.3e fix1 — Spellcast weapon trait

## Cause

DH-DATA legitimately contains four Arcane-Frame Wheelchair weapons whose rules-level Trait is `Spellcast`.
Foundryborne 2.8.2 stores `system.attack.roll.trait` as a choice among the six concrete actor abilities only; the literal value `spellcast` is therefore invalid.

## Fix

- `Spellcast` is no longer treated as a concrete Foundryborne trait.
- For these four weapons the attack roll trait is stored as `null` with `useDefault = true` when that field exists.
- The source semantic is preserved in `flags.daggerheart-campaign-toolkit.sourceAttackTrait = "spellcast"`.
- An explicit mapping gap `system.attack.roll.trait:spellcast-dynamic` remains until the runtime adapter resolves the subclass Spellcast trait on an equipped character.

This is intentionally preferable to inventing one of the six actor traits.
