# P2.3.3f fix1 — adversary direct damage

Fixes Foundryborne 2.8.2 validation failure caused by the SRD attack damage string `40 direct`.

- Only syntactically safe flat/dice formulas are serialized into the native `DHAttackAction`.
- `40 direct` is serialized as numeric formula `40` so the ActionField remains valid.
- The missing Foundry-native semantics of the `direct` rider remains explicit as `system.attack.damage:direct-semantics`.
- Arbitrary extracted damage text is never passed directly to Foundry's Roll parser.
