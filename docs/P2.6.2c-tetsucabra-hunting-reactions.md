# P2.6.2c — Tetsucabra : Hunting Reactions

**Statut : CRISTALLISÉ**

## Profil

Tetsucabra est le premier vertical slice des Hunting Reactions.

```text
Tier 1
Role: Bruiser
Tags: Herbivore, Fouisseur
```

Les Hunting Reactions ne remplacent pas ses actions adversaires normales. Elles ne se déclenchent que dans le protocole Engagement.

---

## Reaction — Coup de boutoir

**Déclenchement :**

```text
Réussite + Fear
ou
Échec + Hope
```

Après la résolution de l'Opener, Tetsucabra effectue immédiatement une attaque contre celui-ci.

```text
Target: Opener
Resolution: attaque adversaire normale
Support window: oui
```

Avant le jet d'attaque, un autre chasseur peut utiliser la fenêtre générique de Support défensif :

```text
1 Hope → -1d4 au jet d'attaque de Tetsucabra
          contre l'Opener
```

La réaction ne retire aucune Opportunité.

---

## Fear Reaction — Charge tectonique

**Déclenchement :**

```text
Échec + Fear
```

Tetsucabra résout d'abord **Coup de boutoir**, avec la même fenêtre de Support défensif.

Il projette ensuite violemment l'Opener sur **2 bandes de portée**, jusqu'à **Close** lorsqu'il part de Melee :

```text
Melee → Very Close → Close
```

Cette projection est un déplacement forcé.

Elle :

- ne retire pas les Opportunités ;
- ne change pas le Finisher désigné ;
- ne nécessite pas un second jet d'attaque ;
- n'est pas annulée par le `-1d4` du Support défensif.

---

## Collision — dégâts de choc

Si un obstacle suffisamment solide empêche de parcourir toute la projection, chaque bande de déplacement non parcourue est convertie en :

```text
1 bande non parcourue → 1d6 dégâts physiques de choc
```

Depuis Melee :

```text
aucun obstacle
→ Melee → Very Close → Close
→ aucun dégât de choc

obstacle à Very Close
→ déplacement jusqu'à Very Close
→ 1 bande restante
→ 1d6 dégâts de choc

obstacle immédiat
→ aucun déplacement
→ 2 bandes restantes
→ 2d6 dégâts de choc
```

Le MJ détermine si l'élément rencontré peut réellement interrompre la projection : paroi, gros rocher, structure massive ou obstacle fictionnel équivalent.

### Frontière

Cette conversion :

```text
distance non parcourue → d6 de choc
```

est une propriété de **Charge tectonique**.

Elle n'est pas une règle universelle de collision d'Engagement.

Une autre créature utilisant un déplacement forcé n'obtient donc pas automatiquement cette mécanique.

## Matrice Tetsucabra

```text
RÉUSSITE + HOPE
2 OP
→ aucune Hunting Reaction
→ Spotlight au Finisher

RÉUSSITE + FEAR
2 OP
→ Coup de boutoir
→ fenêtre Support
→ Finisher

ÉCHEC + HOPE
1 OP
→ Coup de boutoir
→ fenêtre Support
→ Finisher

ÉCHEC + FEAR
1 OP
→ Coup de boutoir
→ fenêtre Support
→ Charge tectonique
   ├─ projection de 2 bandes
   └─ bandes bloquées → 1d6 chacune
→ Finisher
```

---

## Identité mécanique

La réaction normale exprime le risque pris par l'Opener.

La Fear Reaction transforme ce risque en **pression territoriale** :

- le Tetsucabra redistribue les positions ;
- les obstacles deviennent tactiquement importants ;
- la portée de l'arme et des capacités peut changer après l'ouverture ;
- une mauvaise position peut transformer la projection en dégâts ;
- le Finisher conserve néanmoins l'ouverture créée.

Le terrain participe ainsi à l'identité du monstre sans créer de sous-système général de collision.

## Format de données candidat

Le format reste candidat jusqu'à comparaison avec un second profil de monstre :

```json
{
  "hunting": {
    "tags": ["herbivore", "burrower"],
    "reactions": {
      "normal": {
        "name": "Coup de boutoir",
        "target": "opener",
        "supportWindow": true
      },
      "fear": {
        "name": "Charge tectonique",
        "baseReaction": "normal",
        "consequence": {
          "type": "forcedMovement",
          "steps": 2,
          "collision": {
            "damagePerUnspentStep": "1d6",
            "damageType": "physical"
          }
        }
      }
    }
  }
}
```

## Validation

**P2.6.2c = GREEN / CRISTALLISÉ**

Le Tetsucabra démontre qu'une Hunting Reaction renforcée peut :

- caractériser le monstre ;
- exploiter le terrain ;
- laisser intacte la chaîne Opener → Finisher ;
- donner une fenêtre claire au Support ;
- éviter un nouvel état générique ;
- rester résoluble rapidement.
