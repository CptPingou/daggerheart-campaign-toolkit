- Route les 7 familles validées vers 7 compendiums dédiés.
- Retire l'API pilote publique; `pilot-import.mjs` reste temporairement utilisé comme bibliothèque interne de builders jusqu'au nettoyage P2.3.3b final.

Après installation, redémarrer complètement Foundry (module.json change), puis lancer :

```js
await game.modules.get("daggerheart-campaign-toolkit").api.importFullMapped();
await game.modules.get("daggerheart-campaign-toolkit").api.fullStatus();
```
