# P2.3.3e — Equipment mapping

Source authority: the current `DH Data.zip` snapshot supplied by the user.
Target runtime: Foundry VTT 14.367 / Daggerheart 2.8.2.

## Scope

- Weapon attack stat line is mapped from DH-DATA: trait, range, damage die/bonus and physical/magical type.
- Weapon slot, tier and burden remain mapped as before.
- Armor tier, score and thresholds remain mapped as before.
- Equipment feature text is always preserved in the item description.
- When a feature name exactly matches a Foundryborne configured weapon/armor feature, the native feature key is attached.
- Feature actions/effects are not fabricated during pack creation. Such cases remain explicit `:automation` gaps; unmatched configured features remain `:catalog` gaps.
- Semantic audit now treats arrays containing only empty values as neutral, and separately verifies weapon/armor stat-line completeness.

## Validation

After copying the patch and reloading Foundry:

```js
await game.modules.get("daggerheart-campaign-toolkit").api.importFullMapped();
await game.modules.get("daggerheart-campaign-toolkit").api.semanticAudit();
```

Expected import count remains 1012/1012. Weapon `system.attack` should no longer appear as a blanket 358-item mapping gap. Remaining equipment gaps should be limited to feature catalog/automation handling or genuinely unsupported source values.
