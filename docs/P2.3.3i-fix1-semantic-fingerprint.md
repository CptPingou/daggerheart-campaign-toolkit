# P2.3.3i-fix1 — semantic fingerprint

Micro-correctif de l'audit uniquement.

`system.potentialAdversaries` est désormais un objet structuré Foundry. Certains objets TypedObject/DataModel ne sont pas sérialisables directement et l'ancien fallback `String(value)` les transformait tous en `[object Object]`, créant un faux positif de répétition.

Le fingerprint :
- réduit d'abord les DataModel/TypedObject via `toObject(false)` quand disponible ;
- sérialise récursivement tableaux, objets, Map et Set avec ordre stable ;
- gère les cycles sans retomber sur `[object Object]`.

Aucun import n'est nécessaire. Après remplacement du fichier et F5, lancer uniquement :

```js
await game.modules.get("daggerheart-campaign-toolkit").api.semanticAudit();
```

Cible attendue : `repeatedTemplateFingerprints = 0`, `mappingGaps = 654`, `statIssues = 0`, `green = true`.
