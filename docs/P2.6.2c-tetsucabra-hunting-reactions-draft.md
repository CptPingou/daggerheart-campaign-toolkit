# P2.6.2c — Tetsucabra : Hunting Reactions

**Statut : DRAFT — vertical slice Tier 1 Bruiser**

## Objectif

Utiliser Tetsucabra comme premier adversaire de chasse pour vérifier que le modèle :

```text
Reaction
Fear Reaction
```

donne une identité au monstre sans créer un second tour de combat ou une table générique supplémentaire.

Cette passe définit uniquement ses réactions à **Engagement**. Elle ne remplace pas ses actions adversaires normales.

---

## Profil recherché

Tetsucabra est notre cas d'école **Tier 1 Bruiser**, avec les tags Hunting déjà retenus :

```text
Herbivore
Fouisseur
```

Sa réaction doit donc exprimer un monstre :

- brutal ;
- territorial ;
- capable de faire payer à l'Opener son exposition ;
- dont la version renforcée modifie la situation plutôt que de simplement ajouter davantage de dégâts.

---

## Reaction — Coup de boutoir

**Déclenchement :**

```text
Réussite + Fear
ou
Échec + Hope
```

Après la résolution de l'Opener, Tetsucabra effectue immédiatement une attaque contre celui-ci.

```text
Coup de boutoir
Target : Opener
Resolution : attaque adversaire normale
Support window : oui
```

Avant le jet d'attaque, un chasseur peut utiliser la fenêtre générique de Support défensif :

```text
1 Hope → -1d4 au jet d'attaque de Tetsucabra
```

L'attaque ne modifie pas les Opportunités déjà créées.

### Intention

L'Opener a obtenu son ouverture, complète ou imparfaite, mais s'est exposé au monstre.

Le Support peut absorber une partie de ce risque.

---

## Fear Reaction — Charge tectonique

**Déclenchement :**

```text
Échec + Fear
```

Tetsucabra utilise d'abord la même réaction offensive :

```text
Coup de boutoir → Opener
```

avec la même fenêtre de Support défensif.

Puis il impose une conséquence territoriale :

> Tetsucabra fracasse le terrain autour de l'Opener et le repousse jusqu'à Very Close. Le MJ peut déplacer l'Opener vers une position cohérente avec la charge.

Cette conséquence :

- ne retire pas les Opportunités ;
- ne change pas le Finisher désigné ;
- n'ajoute pas un état Hunting générique ;
- ne nécessite pas un second jet d'attaque ;
- n'est pas annulée par le `-1d4` du Support.

Le Finisher conserve donc son ouverture, mais doit exploiter une situation qui vient de changer.

---

## Pourquoi du déplacement plutôt que des dégâts supplémentaires

La Fear Reaction doit être plus dangereuse sans devenir :

```text
attaque
+
encore des dégâts
```

Le déplacement donne au Tetsucabra une identité de Bruiser territorial et permet aux propriétés existantes du jeu — portée, position et déplacement — de reprendre immédiatement de l'importance.

Cela crée également un espace futur pour les cartes Hunting :

```text
Support → empêcher/réduire un déplacement
Finisher → exploiter une cible qui vient de charger
Opener → résister à une réaction territoriale
```

sans ajouter ces exceptions au noyau Engagement.

---

## Résolution complète avec Tetsucabra

```text
RÉUSSITE + HOPE
2 OP
→ aucune Hunting Reaction
→ Spotlight au Finisher

RÉUSSITE + FEAR
2 OP
→ Coup de boutoir contre l'Opener
→ fenêtre Support
→ Finisher

ÉCHEC + HOPE
1 OP
→ Coup de boutoir contre l'Opener
→ fenêtre Support
→ Finisher

ÉCHEC + FEAR
1 OP
→ Coup de boutoir contre l'Opener
→ fenêtre Support
→ déplacement territorial jusqu'à Very Close
→ Finisher
```

---

## Frontière avec les actions adversaires

Une Hunting Reaction n'est pas une action supplémentaire disponible librement au MJ.

Elle possède un déclencheur précis dans Engagement.

```text
normal adversary action
    ≠
Hunting Reaction
```

Le bloc Hunting doit donc être lisible séparément du bloc d'actions adversaires normal.

Conceptuellement :

```text
Tetsucabra
├── Daggerheart adversary data
├── actions / features
└── Hunting
    ├── tags
    │   ├── Herbivore
    │   └── Fouisseur
    └── reactions
        ├── normal
        │   └── Coup de boutoir
        └── fear
            └── Charge tectonique
```

---

## Format de données candidat

Cette structure est volontairement un **candidat**, pas encore un schéma canonique :

```json
{
  "hunting": {
    "tags": ["herbivore", "burrower"],
    "reactions": {
      "normal": {
        "name": "Coup de boutoir",
        "target": "opener",
        "supportWindow": true
      },
      "fear": {
        "name": "Charge tectonique",
        "baseReaction": "normal",
        "consequence": {
          "type": "forcedMovement",
          "range": "veryClose"
        }
      }
    }
  }
}
```

Le schéma définitif ne doit être généralisé qu'après validation en jeu et comparaison avec au moins un adversaire de chasse d'un autre profil.

---

## Critères de validation

P2.6.2c sera GREEN si :

- la réaction normale fait payer l'exposition sans réduire les OP ;
- le Support défensif possède une fenêtre claire ;
- la Fear Reaction ajoute une conséquence caractéristique plutôt qu'un simple bonus de dégâts ;
- le Finisher reste impliqué après les quatre résultats de l'Opener ;
- aucune nouvelle condition générique n'est nécessaire ;
- la mécanique reste suffisamment courte pour être résolue pendant le Spotlight.

## Question de validation

Le seul choix de design encore ouvert dans ce draft est la conséquence de **Charge tectonique**.

Proposition actuelle :

```text
déplacement forcé de l'Opener jusqu'à Very Close
```

Si ce comportement correspond bien au Tetsucabra recherché, P2.6.2c peut être cristallisé sans ajouter d'autre mécanique.
