## Coverage

- 18 / 18 catalog Augments have a usable Foundry representation.
- 8 deterministic passive modifiers are materialized as native ActiveEffects.
- 5 contextual/player-triggered mechanics use native declarative actions.
- 3 passive/contextual mechanics remain passive Weapon Features with rules text only.
- Scope uses a dedicated reversible structural mutation because Foundryborne exposes the weapon range field but no native “+1 range step” ActiveEffect primitive.
- Toolkit state remains authoritative for crafted/installed Augments.
- Native effects/actions are disposable materialization and can be rebuilt with `weaponAugmentState.resync(weapon)`.

## Deliberate non-automation

The following mechanics are intentionally not automated because no clean native Foundryborne primitive was identified:

- Amplify — successful attack → extra damage die, drop lowest.
- Fix — Severe damage trigger → clear 1 HP.
- Scare — critical attack trigger → target marks 1 Stress.
- Absorb — permission to mark one additional Armor Slot against incoming damage.
- Kick — successful attack trigger / target marks additional HP.
- Zip — movement as part of attack.
- Follow — reroll timing.
- Override — attack-roll advantage.

Where an explicit resource payment is simple and native, the action keeps it (Split 1 Stress, Kick 2 Stress, Follow 2 Stress). Passive permissions such as Absorb do not get a separate click action.

## Lifecycle

`weaponAugmentState.resync(weapon)` was validated against Force:

1. remove Toolkit-owned `motherboard-*` native feature entries;
2. Foundryborne deletes linked native effects/actions;
3. rebuild native features from `state.installed`;
4. Foundryborne materializes fresh linked effects/actions with new IDs;
5. non-Motherboard weapon features are preserved.

## Closure decision

**P2.5.5c = GREEN.**

No orphaned Motherboard Augment remains. No corrective runtime patch is required from this audit.
