# P2.3.3a fix6 — déclaration des compendiums full import

Le code `full-import.mjs` cible les packs `dh-items` et `dh-actors`, mais ils doivent être déclarés dans `module.json` au chargement du module.

Ce patch ajoute/conserve explicitement les cinq packs du Campaign Toolkit :
- toolkit-macros
- pilot-items
- pilot-actors
- dh-items
- dh-actors

Version module : 0.3.1.

Après copie du patch, redémarrer complètement Foundry VTT (pas seulement F5), puis rouvrir le monde avant de relancer `importFullMapped()`.
