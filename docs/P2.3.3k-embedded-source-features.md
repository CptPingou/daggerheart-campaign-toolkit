# P2.3.3k — Embedded source features

## Goal
Map the normalized P2.3.3j adversary/environment `features[]` records into native Foundryborne embedded `Item` documents of type `feature`.

## Doctrine
- Preserve DH-DATA as canonical source.
- Clone a native Foundryborne `feature` Item only for schema shape.
- Strip template actions, resources, granter data and effects.
- Import only source feature name, source text and source form (`Passive`, `Action`, `Reaction`).
- Do **not** automate feature mechanics in this milestone.

## Expected corpus
- Adversary features: 899
- Environment features: 189
- Total embedded features: 1088

## Import behavior
Each adversary/environment receives embedded feature Items with:
- `type: feature`
- source feature name
- source text in `system.description`
- `system.featureForm` mapped to `passive`, `action`, or `reaction`
- provenance flags identifying parent source and feature index

Actors store `sourceFeatureCount` in toolkit flags. The semantic audit checks that the number of embedded source features equals this count and that no template automation/resource/effect survived.
