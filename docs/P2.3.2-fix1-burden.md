# P2.3.2 fix1 — Weapon burden enum

Foundryborne 2.8.2 stores weapon burden as a schema choice value, not as the displayed/source label.

The pilot Revolver provides `One-Handed` in DH-DATA. The importer now maps neutral labels (`One-Handed`, `Two-Handed`) to the canonical values exposed at runtime by `CONFIG.DH.GENERAL.burden`. Unknown values no longer invalidate the entire Item import: they leave the native template value in place and emit a console warning.

Expected retest: 5 pilot Items / 2 pilot Actors, then run `mappingAudit()`.
