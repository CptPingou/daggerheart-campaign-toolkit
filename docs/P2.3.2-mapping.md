# P2.3.2 — Mapping sémantique du pilote

Ce patch remplace le simple test de création P2.3.1 par un premier mapping explicite des champs neutres vers Foundryborne 2.8.2.

## Corrigé / mappé
- Blood Hunter: `rules.starting_evasion` → `system.evasion` (le pilote P2.3.1 ne lisait pas la bonne clé).
- Subclass: `rules.spellcast_trait` → `system.spellcastingTrait`; suppression des features/liens hérités du template SRD lorsque ces conteneurs existent.
- Domain card: domain, level, recall cost conservés.
- Weapon: tier, primary/secondary et burden lorsque le champ natif existe; suppression des weaponFeatures héritées du template.
- Armor: tier, armor score et thresholds lorsque les chemins natifs existent; suppression des armorFeatures héritées du template.
- Adversary: correction `motives_tactics` → `system.motivesAndTactics`; tier/difficulty/role conservés.
- Environment: accepte `impulses` sous forme texte (format réel de DH-DATA); tier/difficulty/type conservés.
- Provenance: `mappingVersion: P2.3.2`.

## Volontairement différé
Les structures imbriquées `ActionField` (attaques), features d'arme/armure, features d'adversaire/environnement et liens de features de classe/sous-classe ne sont pas fabriquées à la main. Elles seront mappées à partir de leurs schémas natifs 2.8.2 dans la suite de P2.3.

## Test
Après remplacement des fichiers et F5 :

```js
await game.modules.get("daggerheart-campaign-toolkit").api.importPilot();
await game.modules.get("daggerheart-campaign-toolkit").api.mappingAudit();
```

Attendu : 5 Items / 2 Actors, aucune erreur de validation, et `mappingVersion = P2.3.2` sur les 7 documents.
