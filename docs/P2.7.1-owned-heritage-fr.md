# P2.7.1 — Owned Heritage FR

## But

Faire du Campaign Toolkit la source runtime des ancestries et communities, au lieu d'afficher une traduction par-dessus les compendiums anglais de Foundryborne.

## Packs possédés

- `daggerheart-campaign-toolkit.dh-ancestries`
- `daggerheart-campaign-toolkit.dh-communities`

Chaque document matérialisé reçoit `flags.daggerheart-campaign-toolkit` avec :

- `owned: true`
- `contentOrigin: "core"`
- `contentLocale: "fr"`
- `canonicalId`
- `family`

Ces métadonnées constituent le contrat prévu pour le homebrew : `contentOrigin` pourra devenir `monster-hunter`, `eberron`, etc., sans changer le chemin de consommation Foundryborne.

## Bootstrap P2.7.1

À la première ouverture GM après installation de ce patch, le Toolkit copie la structure mécanique des packs système `daggerheart.ancestries` et `daggerheart.communities`, réécrit leurs UUID internes vers les packs Toolkit et matérialise les textes FR de `locales/fr.json` dans les documents possédés.

Après matérialisation, le Compendium Browser exclut les quatre packs système classes/subclasses/ancestries/communities et utilise les packs Toolkit. La couche de présentation ancestry/community pointe elle aussi vers les packs Toolkit.

Ce bootstrap est volontairement une étape de migration : il permet de produire immédiatement des documents Foundry natifs complets sans reconstruire à la main les effets/actions mécaniques. L'étape suivante pourra figer ces documents comme données source versionnées du Toolkit et supprimer le bootstrap SRD.

## Console

```js
await game.modules.get("daggerheart-campaign-toolkit").api.ownedHeritageStatus()
```

Reconstruction forcée :

```js
await game.modules.get("daggerheart-campaign-toolkit").api.materializeOwnedHeritage({ force: true })
```

Attendu : 24 ancestries et 15 communities pour le SRD 2.0 actuellement traduit, avec leurs features associées.
