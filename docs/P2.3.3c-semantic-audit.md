# P2.3.3c — Audit sémantique post-import

Objectif : détecter les reliquats éventuels du document SRD utilisé comme template par le mapper P2.3.x.

L'audit est strictement en lecture seule. Il vérifie :

- la présence de la provenance (`sourceId`, `sourcePath`, `mappingVersion`) sur les 1012 documents gérés ;
- les champs sensibles susceptibles de conserver du contenu du template SRD ;
- les empreintes non vides identiques répétées sur une part importante d'une famille ;
- les Items embarqués répétés pour Adversaries et Environments.

Une empreinte répétée n'est pas automatiquement une erreur : elle signale un champ à examiner avant de considérer le mapping sémantiquement fidèle.

Commande Foundry :

```js
await game.modules.get("daggerheart-campaign-toolkit").api.semanticAudit();
```

Ne pas modifier les compendiums à la main à partir de cet audit. Les corrections doivent rester dans le mapper.
