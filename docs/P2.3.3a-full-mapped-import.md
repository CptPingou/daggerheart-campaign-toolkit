# P2.3.3a — import complet des familles validées

Étend le mapping P2.3.2 aux sept familles déjà validées sur Foundry 14.367 / Daggerheart 2.8.2 : class, subclass, domain_card, weapon, armor, adversary, environment.

Cette étape est volontairement P2.3.3a : les familles non encore pilotées (ancestry, community, consumable, loot, beastform…) ne sont pas injectées avant validation de leur mapping natif.

Le nouvel import est géré dans deux compendiums `dh-items` et `dh-actors`. Il remplace uniquement les documents portant le flag `managed`; les compendiums pilotes restent séparés.
