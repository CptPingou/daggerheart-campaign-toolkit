# P2.2 — Blood domain migration fix

Micro-patch 0.2.1.

Le Campaign Toolkit enregistre désormais synchroniquement le domaine `blood` pendant le hook `init`, avant l’initialisation des Items du monde. Cela permet aux anciennes Domain Cards Blood déjà présentes dans le monde de rester valides lorsque le module séparé Blood Hunter v1.5 est désactivé.

Test attendu après remplacement des fichiers et F5 :

- console : `daggerheart-campaign-toolkit | Blood domain registered`
- disparition des erreurs `domain: blood is not a valid choice`
- ancien module Blood Hunter reste désactivé
- ne pas lancer `importPilot()` avant validation de ce test
