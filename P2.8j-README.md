# P2.8j — Opportunity Direct World Writer

Changed file only:
- `scripts/engagement-opportunity.mjs`

## What changes

Opportunity mutations no longer depend on the Foundryborne Countdown UI or DOM.

The authoritative storage remains the Foundryborne World setting:

`daggerheart.Countdowns`

The Toolkit now updates `progress.current` directly and persists it with
`game.settings.set(...)`.

### API

Existing API remains:
- `getOpportunityValue()`
- `increaseOpportunity(amount)`
- `decreaseOpportunity(amount)`
- `clearOpportunity()`

New:
- `setOpportunity(value)`

Writes are GM-only and clamp Opportunity between `0` and the countdown's
`progress.start` (currently Tier 1 = 4).

The Countdown UI is re-rendered when already open, but it is no longer required
for mechanics to work.

## Validation

Run as GM:

```js
const opp = game.modules.get("daggerheart-campaign-toolkit").api.engagementOpportunity;

console.log("before", opp.status());
console.log("set 1", await opp.setOpportunity(1));
console.log("+2", await opp.increaseOpportunity(2));
console.log("-1", await opp.decreaseOpportunity(1));
console.log("clear", await opp.clearOpportunity());
console.log("after", opp.status());
```

Expected sequence: `1`, `3`, `2`, `0`.

Clamp checks:

```js
console.log(await opp.setOpportunity(99)); // 4
console.log(await opp.decreaseOpportunity(99)); // 0
```
