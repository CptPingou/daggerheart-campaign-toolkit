# P2.8k.2 — Monster Reaction Chat Notice

Quand `reactionRequired` vaut `true`, le client qui a résolu l'Ouverture publie
un simple message dans le chat.

Aucune automatisation de la réaction :
- pas de ciblage ;
- pas de sélection d'attaque ;
- pas de jet ;
- le MJ choisit et résout normalement l'attaque appropriée.

Le message porte seulement des flags de traçabilité (message source, outcome,
Actor/Token de l'Opener). La mutation Opportunity existante est inchangée.
