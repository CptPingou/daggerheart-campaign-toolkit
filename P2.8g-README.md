# P2.8g — Actor Hunt-card Loadout Adapter

Premier raccord entre les cartes Chasse mécaniques et un Actor réel.

Cette passe est read-only : elle détecte les cartes Monster Hunter embarquées
sur l'Actor, ignore les cartes sans `huntCardMechanic`, valide la limite de
2 cartes et expose les capacités `opener / finisher / support`.

## Validation

Après extraction + F5 :

```js
const api = game.modules.get("daggerheart-campaign-toolkit").api;
console.log(api.monsterHunterActorLoadout.status());
```

Attendu : `green: true`, `maxLoadoutCards: 2`.

Sur un token de PJ sélectionné :

```js
const actor = canvas.tokens.controlled[0]?.actor;
console.log(api.monsterHunterActorLoadout.inspect(actor));
console.log(api.monsterHunterActorLoadout.capabilities(actor));
```

Avec 2 cartes mécaniques : GREEN. Avec Ouverture + Conversion + Appui
défensif : `count: 3`, refus `max-loadout`.

Non-régression :

```js
console.log(api.monsterHunterEngagement.status().green);
console.log(api.monsterHunterOpportunity.status().green);
console.log(api.monsterHunterHuntCard.status().green);
const s = await api.autonomousSourceStatus();
console.log(s.expected, s.actual, s.green);
```

Attendu : trois `true`, puis `811 811 true`.
