# P2.8i — Opportunity World Bootstrap

Changed file only:
- `scripts/engagement-opportunity.mjs`

## What changes

- `Opportunity` is now bootstrapped from the authoritative Foundryborne World setting `daggerheart.Countdowns`.
- Fresh worlds receive a stable Toolkit countdown key: `DCTOpportunity01`.
- Existing worlds such as `daggerTest` are preserved: an existing countdown named `Opportunity` is reused and is not duplicated.
- Bootstrap runs once on `ready`, GM-only.
- API additions:
  - `game.modules.get("daggerheart-campaign-toolkit").api.engagementOpportunity.ensure()`
  - `game.modules.get("daggerheart-campaign-toolkit").api.engagementOpportunity.status()`
- Reads no longer require the Countdown UI cache; the World setting is authoritative.
- Existing increase/decrease behavior is intentionally unchanged in this pass and still uses Foundryborne's native Countdown actions.

## Validation

After F5 as GM:

```js
const opp = game.modules.get("daggerheart-campaign-toolkit").api.engagementOpportunity;
console.log(opp.status());
console.log(game.settings.get(CONFIG.DH.id, CONFIG.DH.SETTINGS.gameSettings.Countdowns));
```

Expected in `daggerTest`: `green: true`, `legacy: true`, same existing countdown, no duplicate.

In a fresh World: `green: true`, `legacy: false`, id `DCTOpportunity01`, name `Opportunity`, start `4`, current `0`.
