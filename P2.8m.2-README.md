# P2.8m.2 — Autonomous Domain Action Preservation

Diagnostic confirmé sur Foundryborne :
- les cartes natives `daggerheart.domains` exposent 190/210 `system.actions`;
- `system.actions` est un objet indexé par ID;
- les sources Toolkit contiennent bien ces objets;
- `Item.createDocuments()` les perd, tandis que `Document#update()` est déjà
  un chemin validé par le Toolkit pour créer des actions Daggerheart.

Correction limitée au synchroniseur autonome :
1. création des `domainCard` sans actions ;
2. matérialisation de `system.actions` immédiatement après création via `doc.update()`;
3. la normalisation de vérification conserve les actions autoritatives de la source,
   afin que `autonomousSourceStatus()` détecte désormais une perte réelle d'actions.

Aucune donnée de carte n'est modifiée par ce patch.
