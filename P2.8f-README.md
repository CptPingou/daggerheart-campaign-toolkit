# P2.8f — First Mechanical Hunt Cards

Ajoute 3 vraies cartes de domaine Chasse mécaniques au corpus Monster Hunter :

- **Ouverture** — Opener, 2 Espoir, génère 2 OP.
- **Conversion** — Finisher, convertit les OP en dégâts ou Effet ; critique = dégâts + Effet.
- **Appui défensif** — Support, 1 Espoir, -1d4 à l'attaque du monstre contre un engagé.

Les 5 cartes de rôle (Naturaliste, Traqueur, Tacticien, Cuistot, Extracteur)
restent distinctes. Le corpus MH passe de 5 à 8 cartes.

Le comportement mécanique est stocké dans
`flags.daggerheart-campaign-toolkit.huntCardMechanic` et validé par le schéma
P2.8e. L'arme ne porte aucun rôle Engagement.

## Validation

Après extraction + F5 :

```js
const api = game.modules.get("daggerheart-campaign-toolkit").api;
const s = await api.autonomousSourceStatus();
console.log(s.expected, s.actual, s.green);
console.log(s.packs["dh-domain-cards"]);
```

Attendu avant sync : 811 / 808, 3 cartes manquantes.

Puis :

```js
await api.syncAutonomousSources();

const s2 = await api.autonomousSourceStatus();
console.log(s2.expected, s2.actual, s2.green);
console.log(s2.packs["dh-domain-cards"]);

console.log(await api.monsterHunterHuntCard.corpusStatus());
```

Attendu :
- 811 / 811 GREEN
- `dh-domain-cards` 239 / 239
- corpus MH : 8 cartes
- cartes mécaniques : 3
- `missingMechanicalIds: []`
- `green: true`
